# Лысый и менты 3D

3D-версия игры «Baldy and cops» для телефона. Открывается прямо в браузере —
ничего устанавливать не надо.

**Суть та же, что в оригинале на PyGame:** ты — Лысый, по лабиринту тебя ищут
менты (поиск пути в ширину, как в `br.py`), надо найти выход. Только теперь всё
от третьего лица, в объёме и с нормальным светом.

## Запуск на телефоне

Игра уже выложена на GitHub Pages:

**https://idyadyavova.github.io/baldy_and_cops/**

Косая черта в конце обязательна. Дальше «Добавить на главный экран» —
запустится на весь экран, как приложение.

Если включаешь Pages заново: Settings → Pages → Deploy from a branch →
ветка `claude/3d-mobile-game-shaders-72vq55`, папка `/ (root)` → Save,
и подождать 1–2 минуты, пока соберётся.

Локально:

```
python -m http.server 8000
```

и открыть `http://<ip-компьютера>:8000/` с телефона в той же сети.
Файл `index.html` можно открыть и напрямую (двойным кликом) — всё работает офлайн,
three.js лежит в `vendor/`.

Нужен браузер с WebGL 2: Chrome, Safari 15+, любой современный мобильный браузер.

## Управление

| Действие | Телефон | Клавиатура |
|---|---|---|
| Идти | джойстик слева | WASD / стрелки |
| Камера | палец по правой половине экрана | зажать мышь и вести |
| Бег | кнопка «БЕГ» | Shift |
| Прыжок | кнопка «ПРЫЖОК» | Пробел |
| Пауза | кнопка «II» | Esc |

## Что в игре

- Три уровня — это три карты из `map_game.json` оригинала: «Простой» (утро),
  «Средний» (закат), «Сложный» (ночь, 40×40, пять ментов).
- Менты ищут путь поиском в ширину; если увидели — свисток, сирена и погоня напрямую.
- Монеты, таймер, рекорды по каждой сложности, мини-карта с туманом войны.
- Четыре персонажа на выбор.

## Как это нарисовано

В репозитории нет ни одной картинки — вся графика считается кодом при запуске.

- **Материалы** (`src/textures.js`) — процедурные, 256×256 на блок: альбедо,
  карта нормалей, шероховатость, высота и AO. Камень собирается из клеток Вороного
  с трещинами и мхом, трава — из тысяч отдельных нарисованных травинок,
  кора — из гребней ridged-шума, и так далее. Тайлы лежат в текстурном массиве
  (`DataArrayTexture`) с честной мип-цепочкой — без «протечек» между блоками.
- **Рельеф камня настоящий**, а не нарисованный: parallax occlusion mapping
  (`src/materials.js`) шагает по карте высот прямо в пиксельном шейдере.
- **Персонажи** (`src/character.js`) — не кубики: тело построено лофтом
  эллиптических сечений (грудь, руки, ноги сужаются как надо), голова —
  деформированная сфера с ушами, носом, бровями и глазами. Анимация процедурная:
  шаг, бег, наклон корпуса, дыхание, моргание, испуг.
- **Свет** (`src/shaderlib.js`) — GGX + рассеяние в коже, мягкие тени PCF со
  смещением по нормали, небесный ambient, отскок света от земли, фонари как
  точечные источники, объёмный туман с подсветкой от солнца.
- **Небо** (`src/sky.js`) — аналитическое: рассеяние Ми вокруг солнца, три слоя
  облаков с параллаксом и подсветкой кромки, луна с кратерами, звёзды и Млечный Путь.
- **Мелочи, которые делают картинку живой** — плющ на стенах и кусты травы
  качаются от ветра прямо в вершинном шейдере, в воздухе висит пыль
  (ночью — светлячки), стены лабиринта чередуют камень, булыжник, кирпич и
  живую изгородь.
- **Вода** (`src/water.js`) — две прокручивающиеся карты нормалей, френель,
  отражение неба, блик солнца, глубинный цвет.
- **Постобработка** (`src/post.js`) — bloom по мип-цепочке, объёмные лучи из-за
  солнца, SSAO, ACES-тонмаппинг, цветокоррекция, виньетка, зерно, FXAA.

## Производительность

В меню «Графика» — четыре пресета. На слабом телефоне ставь «Низк.»: отключаются
parallax, SSAO и лучи, падает разрешение теней. Плюс игра сама снижает внутреннее
разрешение, если кадры проседают ниже ~34 fps.
